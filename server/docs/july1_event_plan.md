# 建党节欢庆活动流程安排（2026年7月1日）

## 一、活动主题
不忘初心跟党走，砥砺奋进新征程

## 二、活动时间
2026年7月1日（星期三）上午9:00–下午16:30

## 三、活动地点
社区文化广场 / 党群服务中心多功能厅

## 四、主要流程

### 09:00–09:30 签到与暖场
- 参与者签到、领取党徽与纪念手册
- 播放红色经典背景音乐（《红旗颂》《没有共产党就没有新中国》）

### 09:30–10:00 开幕式
- 全体肃立，奏唱国歌
- 党组织负责人致辞
- 新党员入党宣誓仪式（重温入党誓词）

### 10:00–11:30 主题学习与分享
- 微党课：《百年征程中的青年担当》（20分钟）
- 老党员故事分享（3位，各10分钟）
- 青年代表交流发言（2人，各5分钟）

### 11:30–12:30 红色知识趣味竞答
- 分组抢答（含党史、二十大精神、本地红色资源等内容）
- 设置“最佳团队奖”“党史达人奖”等小奖品

### 12:30–13:30 午餐与自由交流
- 提供简餐（含“红船粽”“初心糕”等主题餐点）

### 13:30–15:00 实践体验环节
- “我为群众办实事”志愿服务启动（现场认领微心愿）
- 红色剪纸/书法体验区（邀请非遗传承人指导）

### 15:00–16:00 文艺汇演
- 合唱《唱支山歌给党听》
- 诗朗诵《七月的天空》
- 舞蹈《灯火里的中国》
- 儿童合唱《我们是共产主义接班人》

### 16:00–16:30 闭幕与合影
- 颁发参与纪念证书
- 全体合影留念
- 活动总结与后续倡议

## 五、注意事项
- 请佩戴党员徽章或统一发放的红色标识
- 活动全程注意安全，志愿者全程引导
- 如遇雨天，主会场移至党群服务中心室内
